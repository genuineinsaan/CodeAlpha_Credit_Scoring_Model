# 💳 Credit Scoring & Bank Eligibility System

An end-to-end Machine Learning application that predicts customer creditworthiness, generates a credit score, assesses lending risk, and recommends eligible banks through an interactive Flask web application.

Built using Python, Scikit-Learn, Flask, Pandas, and Random Forest Classification.

---

## 🚀 Features

* Credit Risk Prediction using Machine Learning
* Dynamic Credit Score Generation (0–100)
* Loan Approval / Rejection Analysis
* Risk Level Assessment
* Bank Eligibility Recommendations
* Application ID Generation
* Customer Profile Summary
* Strength & Weakness Analysis
* Interactive Flask Web Interface
* Responsive and Professional Dashboard

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/CodeAlpha_Credit_Scoring_Model.git
```

Move into the project directory:

```bash
cd CodeAlpha_Credit_Scoring_Model
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open in your browser:

```text
http://127.0.0.1:5000
```
